Multi-Phase Orchestration Engine

The /clone-website Autonomous Pipeline

Instead of loose approximations or guessing layouts, the agent operates like a site foreman inspecting every computed style, writing auditable specs, and delegating to specialist builder subagents in git worktrees.

1

Reconnaissance

Captures full-page screenshots at desktop, tablet, and mobile. Sweeps hover, click, and responsive states via Chrome MCP.

Output: docs/design-references/
2

Foundation

Extracts design tokens into Tailwind v4 oklch CSS variables. Downloads all images, SVGs, and fonts into isolated public assets.

Output: globals.css & public/
3

Component Specs

Runs `getComputedStyle()` queries to capture exact pixel dimensions, paddings, shadows, and responsive shift breakpoints.

Output: docs/research/components/
4

Parallel Build

Dispatches isolated subagents in git worktrees, each dedicated to coding a single component using strict TypeScript and Radix.

Output: src/components/sites/
5

Assembly & QA

Merges worktrees, hooks page router, validates TypeScript & ESLint, and conducts pixel-by-pixel visual diffing.

Output: Verified App Router Page

1. Completeness Beats Speed

Every builder agent receives full inline context: screenshots, exact computed CSS values, downloaded asset paths, real text copy, and component hierarchy. No agent ever guesses styling or placeholders.

2. Collision-Resistant Route Isolation

Cloning multiple URLs assigns a unique `` and `` hash. Existing authored routes are never overwritten, enabling multi-site and multi-page preservation in one Next.js project.
